Complete guide

From first click to a published paperback. Every panel is collapsed: open what you need.

1Quick start (the whole process in 10 steps)
  1. Choose season, theme, audience, page count and trim size in the left panel. Type a title or leave it empty.
  2. Press Generate My Book. Read the Style Lock card: that is the look every page will share.
  3. Skim the page list. Use Swap this page on any scene you do not like. Use New Scenes or Re-roll Style if you want a bigger change.
  4. Click Export All as .txt to keep a backup of the whole prompt pack (the app saves nothing).
  5. Open a new ChatGPT chat and send the opening message (button in the next panel).
  6. Paste page 1, check the image, regenerate if needed, download the PNG. Repeat for every page.
  7. Open a NEW chat for the covers (they are full colour, not coloring pages). Generate the three front covers, the back cover image and the title page, then pick the best.
  8. Build the interior in Canva at your exact trim size, with a blank page behind each coloring page.
  9. Export the interior as PDF at 300 DPI and make the cover using KDP's cover calculator dimensions.
  10. Paste the listing kit into KDP, answer the AI-content question honestly, preview, and publish.
Plan roughly an hour for a first book (most of it is generating and checking images). Generation limits depend on your ChatGPT plan.
2Generating your pages in ChatGPT (detailed)
Set up the chat
  1. Start one new chat per book. Keep the entire book in that chat so the style stays consistent.
  2. Send the opening message below. It contains your Style Lock and asks ChatGPT to wait for page prompts.
  3. Paste prompts one at a time, in page order. Each prompt already includes the lock, so it still works if you ever have to open a fresh chat.
Opening message (uses your current book's Style Lock)

I am making a coloring book and will send one page prompt at a time. Use the STYLE LOCK below for every image in this chat and never change it from page to page. Reply only "Ready" and wait for my first page prompt. [your Style Lock block is added here]

Check every image
  • Pure black lines on a pure white background. No gray, no shading, no solid black areas.
  • Every shape closed, so it can be coloured in. No broken or open lines.
  • Nothing touches or is cut off at the edges (0.5 in clean margin).
  • No text, letters, numbers or signatures (except the title page, which allows "This book belongs to").
  • Line weight and detail level look the same as the previous pages.
  • Look for odd anatomy, extra limbs, strange objects or unreadable details. Regenerate if anything looks wrong.

3Choosing your settings
  • Audience: Kids gets thick lines and big simple shapes. Adults gets fine intricate detail. Seniors gets large clear shapes with generous spacing. This changes the density wording in the lock.
  • Trim size: 8.5 × 11 in is the most common coloring-book size. 8.5 × 8.5 in is a good square format for kids. 6 × 9 in is compact and travels well, but pages feel smaller.
  • Page count: 20, 25 or 30 designs. Because each design gets a blank page behind it, your PDF will have about double that many pages. Check KDP's price calculator, since printing cost rises with page count.
  • Themes with "Mandalas" or "Patterns" are repetitive-pattern books: great for adults and seniors, and usually the fastest to generate cleanly.
  • Seed: the same seed with the same settings always rebuilds the same book. Copy the seed if you want to come back to a book.
4Troubleshooting
ProblemWhat to try
Pages come out gray or with shadingUse the "Gray or shaded lines" fix message. If it keeps happening, start a new chat and paste the Style Lock first.
Style changes after 10+ pagesLong chats drift. Send the "Style drifted" fix, or open a new chat, paste the opening message and continue from that page.
Subjects look different from the promptRegenerate once. If it still misses, use Swap this page for a simpler scene.
Title on the cover is misspelledRegenerate, or generate the cover with a blank title area and add the text in Canva.
Image is not the right shapePlace it in Canva at your trim size and scale or crop. Keep important parts away from the edges.
Copy button does nothingUse the Export .txt button, or select the text and copy it manually.
Only a few scenes fit when swappingSwap follows the no-adjacent-composition rule. Use New Scenes (keep style) for a fresh list.
5Assemble your interior in Canva
  1. Create a custom design using your exact trim size in inches (for example 8.5 × 11).
  2. Add the title page first ("This book belongs to"), then one coloring page per page.
  3. Scale each image so its artwork stays inside the margins. Use Canva's rulers or guides to keep about 0.5 in clear on every side.
  4. Add a blank page after every coloring page, so marker ink cannot bleed through to the next picture. Pages then print on one side only.
  5. Optional: add a copyright page and a short "Thank you" page at the end. Use only text you wrote or are allowed to use.
  6. Download as PDF Print at 300 DPI. Open the PDF and flip through every page.
  7. KDP paperbacks need at least 24 pages in total. Blank pages count toward the total.

7Using the listing kit
  • Title and subtitle: the main keyword comes first because shoppers search with it. Keep them readable, accurate and free of other brands' names.
  • Description: short paragraphs, benefit-focused. Edit it so it matches what your finished book really contains.
  • Keywords: seven phrases for KDP's seven keyword boxes. Each box can hold a phrase; do not repeat words that already appear in your title.
  • Generate again: press New Book for a different set of phrases and compare. Pick what reads best.
8FAQ
Does this app create the images?
No. It writes the plan and prompts. You create the images yourself in ChatGPT (GPT Image).
Does it need internet?
The studio itself works offline. ChatGPT, Canva and KDP need internet.
Is anything saved?
No. Close the tab and the book is gone. Use Export All as .txt to keep it.
Why one chat per book?
The same chat helps the model keep the same line style from page to page.
Can I use another image tool?
You can try, but the prompts are written and tested around ChatGPT image generation, and results vary by tool.
Will my books sell?
No one can promise that. Quality, niche choice, pricing and marketing all matter, and results vary.
