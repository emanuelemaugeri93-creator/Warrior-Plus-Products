📐 Step 1: Generate & Save Your Pages
  1. Copy each of the 3 prompts and paste them into GPT Image 2 one at a time.
  2. Save each image with right-click → "Save image" to get native high-res export.
  3. Rename files as cover.png, interior-main.png, divider.png.
  4. If any export is below 300 DPI at your trim size, upscale in Canva or Photoshop before proceeding.
📁 Step 2: Assemble Your Interior File
  1. Create a new document at your exact trim size (e.g., 6×9in = 1800×2700px @ 300 DPI).
  2. Place interior-main.png as the main repeatable page.
  3. Insert divider.png between sections (e.g., after every 20 pages).
  4. Duplicate the main page for the total number of pages you need — KDP requires minimum 24 pages for paperback.
  5. Export as print-ready PDF with margins set per KDP requirements (minimum 0.25in, recommended 0.5in inside margin).
🎨 Step 3: Cover File Specs
  • KDP cover must be one full spread: back cover + spine + front cover.
  • Your generated cover is the front cover only — you must add spine and back cover separately.
  • Use KDP's Cover Calculator to get exact dimensions based on your page count and trim size.
  • Export cover as separate PDF or PNG, minimum 300 DPI.
  • For print, include 0.125in bleed on all sides if using full-bleed art.
📦 Step 4: KDP Upload & Preview
  1. Sign in to kdp.amazon.com → Create New Title → Paperback or Hardcopy.
  2. Enter your book details (title, author, description, keywords).
  3. Upload your interior PDF (single file containing all pages in order).
  4. Upload your cover file separately.
  5. Use KDP's Preview tool to check every page for cropping, margins, and text alignment.
  6. Order a physical proof copy before publishing — never skip this step.
✅ Final Pre-Publish Checklist
  • All text is legible and correctly spelled in generated pages.
  • Margins are consistent on every page (no text near edges).
  • Page count matches your book description (KDP shows this on detail page).
  • Cover spine text is centered and readable.
  • Interior pages use consistent style (yours will — that's the point of the Style Lock).
  • No watermarks, mockup frames, or 3D effects remain in generated art.
  • You have a legal right to all content (no copyrighted text or images).
  • Your book title and author name appear on the cover exactly as entered in KDP.
